Project #15: An Automated Assessment Grader using ChatGPT

Back

Description:

This project aims to investigate the use of an LLM to help grade student assessments, specially open ended assessments, similar to the once used in design courses. The students will first investigate the use of ChatGPT, and compare this against other LLMs. Using the ChatGPT API, students will look at the best way to implement an automated assessment grader in Python. 

Using the ELECTENG/COMPSYS 209 laboratory assessments, the viability of the automated grading tool developed will be investigated and improved. 

Type:

Undergraduate

Outcome:

- An automated assessment grader

- Comparison of existing LLMs as a grading tool

- An assessment of feasibility of using ChatGPT or another LLM as an automated assessment grader
